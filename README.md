# Programming Assignments - UNEB 🎓

Este repositório é um arquivo centralizado de estudos, atividades e projetos desenvolvidos durante a minha graduação em **Sistemas de Informação** na **Universidade do Estado da Bahia (UNEB)**.

O foco aqui é a organização por disciplinas, documentando a evolução em lógica, paradigmas de programação e arquitetura de software.

---

## 📚 Disciplinas e Conteúdos

| Disciplina | Linguagem | Tópicos Principais | Status |
| :--- | :---: | :--- | :---: |
| **Linguagem de Programação II (LP2)** | `Java` | POO, UML, Encapsulamento e Herança. | 🏗️ Ativo |
| **Estrutura de Dados I (ED1)** | `C++` | Pilhas, Filas, Listas Encadeadas e Ponteiros. | 🏗️ Ativo |
| **Linguagem de Programação I (LP1)** | `C` | Modularização, ponteiros e manipulação de arquivos. | ✅ Concluído |
| **Algoritmos** | `C` | Lógica de programação e estruturas de controle. | ✅ Concluído |

---

## 🛠️ Tecnologias & Ambiente

* **SO:** Desenvolvido em **Ubuntu 24.04 LTS** (Acer Nitro 5).
* **Linguagens:** Java (JDK 17+), C++, C e Python.
* **Ferramentas:** VS Code, BlueJ, IntelliJ, Git e GitHub.
* **Modelagem:** Diagramas de Classe UML para representação de sistemas.

---

## 📂 Organização das Pastas

Para manter o código limpo e profissional, cada diretório de disciplina segue este padrão:
* `src/`: Apenas arquivos de código fonte (ex: `.java`, `.cpp`, `.c`).
* `bin/`: Arquivos compilados (ignorados pelo Git via `.gitignore`).
* `*.png`: Diagramas UML e documentação visual das atividades.
